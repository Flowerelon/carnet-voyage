# Carnet Hanoï–Tokyo

Carnet de voyage en carte 3D (Vietnam, Philippines, Tokyo, sept.–oct. 2026) : page statique, relief tiré des tuiles d'élévation Terrarium (AWS Open Data), rendu Three.js. Instantané public sans références de réservation ; la version vivante (propositions de Claude, carnet, mise à jour des billets) est privée sur claude.ai.
